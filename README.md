# aulamatematica

Criação de aulas de matemática.

## Aulas

### Escada dos Polinômios (pré-ITA)

Arquivo: [`aula-polinomios-ita.html`](aula-polinomios-ita.html). Abra no navegador (precisa de internet para renderizar as fórmulas).

Aula de polinômios em **escada de progressão**: seis degraus, do básico até o nível das
questões de polinômios da 1ª fase do **ITA 2027** (Questões 10 e 12), que ficam no topo
com dicas graduais e resolução comentada.

| Degrau | Conteúdo | Prepara para |
|---|---|---|
| 1 | Linguagem: grau, valor numérico, $p(0)$, $p(1)$, identidade | Q10 |
| 2 | Divisão, Briot-Ruffini, Teorema do Resto | base |
| 3 | Raízes, forma fatorada, raízes conjugadas, raízes inteiras | Q10, Q12 |
| 4 | Relações de Girard (sinal do produto no grau par/ímpar) | Q12 |
| 5 | Grau como ferramenta: composição e cancelamento do termo líder | Q10 |
| 6 | Polinômios e inteiros: restos, primos, $p(n)$ múltiplo de $m$ | Q12 |
| Topo | ITA 2027 Q10 (resp. E, $-15$) e Q12 (resp. B, $600$) | — |

Cada degrau tem: ideia central, exemplo resolvido, pegadinha, treino com gabarito
escondido e checkpoint (o progresso fica salvo no navegador do aluno). No fim há um
roteiro sugerido de 3 encontros de 100 minutos para o professor.
